# Changelog

All notable changes to the VERITY project are documented here.

---

## [v1.0.0] - 2026-04-23

### Added
- Initial project setup with React + Vite frontend
- Express.js backend with Prisma ORM
- PostgreSQL database integration
- JWT-based authentication system
- Role-based access control (Student, Lecturer, Manager)
- Student Dashboard with Calendar view
- Project Management module with Kanban board
- Announcements module with file attachment support
- Manager Profile administration page
- Real-time notifications via Socket.IO
- Redis-backed background job queue (BullMQ)
- AI-powered features using Google Gemini API
- Supabase integration for file storage

### Fixed
- Session management with secure JWT tokens
- CORS configuration for local development
- Prisma schema migrations

---
